# 알고리즘 학습 로드맵

## 목표
- 자료구조/알고리즘의 기본 개념을 익힌다.
- 코딩 테스트에서 자주 나오는 유형을 반복적으로 푼다.
- 이직 준비를 위한 GitHub 기반 학습 기록을 만든다.

## 단계별 계획

### 1단계: 기초
- 배열, 문자열
- 해시, 스택, 큐
- 연결 리스트
- 구현 연습

### 2단계: 탐색
- DFS / BFS
- 백트래킹
- 이진 탐색

### 3단계: 그래프와 최단 경로
- 그래프 표현
- 우선순위 큐
- 다익스트라
- BFS 기반 최단거리

### 4단계: 동적 계획법
- 1D DP
- 2D DP
- LIS, LCS, 배낭 문제

### 5단계: 고급 테크닉
- 그리디
- 투 포인터
- 슬라이딩 윈도우
- 분할 정복

### 6단계: 실전 연습
- 난이도별 문제 풀이
- 시간 복잡도 분석
- 오답 노트 재복습

## 매주 진행 방식
- 매일 1~2개 문제 풀이
- 주 1회 개념 정리
- 주 1회 회고 작성
- 미해결 문제 재시도
