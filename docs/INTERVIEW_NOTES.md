# 면접용 정리 노트

## 자기소개와 연결하기
- 어떤 알고리즘을 자주 공부했는지
- 어떤 유형에 약했고, 어떻게 보완했는지
- 코딩 테스트 준비 과정에서 어떤 습관을 들였는지

## 설명 포인트
- 문제를 어떻게 분석하는지
- 상태 정의를 어떻게 잡는지
- 시간 복잡도를 어떻게 계산하는지
- 왜 이 알고리즘을 선택했는지

## 자주 나오는 질문
- DP를 왜 쓰는가?
- DFS와 BFS의 차이는 무엇인가?
- 그리디가 항상 최적해를 보장하나?
- 어떤 문제에서 투 포인터가 유용한가?
- 재귀와 반복문 중 어떤 선택이 적합한가?
