# Algorithm

알고리즘 학습 및 이직 준비용 저장소입니다.

## 목표
- 자료구조와 알고리즘 개념을 체계적으로 정리한다.
- 코딩 테스트 대비를 위한 문제 풀이 습관을 만든다.
- 문제 해결 과정과 회고를 남겨 GitHub 이력으로 활용한다.
- 이직 준비 시 학습 포트폴리오로 참고할 수 있도록 관리한다.

## 폴더 구성

- `topics/` : 알고리즘 개념 및 핵심 이론 정리
- `problems/solved/` : 풀이 완료한 문제 기록
- `problems/unsolved/` : 다시 풀어볼 문제 및 막힌 문제 기록
- `notes/` : 일일 학습 메모, 주간 회고
- `docs/` : 로드맵, 체크리스트, 면접 정리
- `code/` : 구현 코드 보관
- `templates/` : 문제/개념 기록 템플릿

## 학습 섹션

- DP
- DFS / BFS
- Greedy
- Graph
- Binary Search
- Heap
- String
- Array / Hash / Stack / Queue

## 관리 방식

1. 오늘 풀 문제를 선정한다.
2. 개념이 약한 부분은 `topics/`에 정리한다.
3. 해결한 문제는 `problems/solved/`에 기록한다.
4. 막히는 문제는 `problems/unsolved/`에 남긴다.
5. 매주 `notes/weekly-review/`에 회고를 작성한다.
6. 구현 코드는 `code/` 폴더에 정리한다.
