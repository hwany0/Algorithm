# 2026-11-14 01 Matrix: BFS 시작점과 시간복잡도 정리

## 오늘의 핵심
오늘은 `542. 01 Matrix` 문제를 다시 보면서,
"왜 0을 시작점으로 BFS를 돌리는지"와
"왜 각 1마다 BFS를 돌리면 타임아웃이 나는지"를 정리했다.

핵심은 다음과 같다.

- 이 문제의 정답은 각 1칸이 가장 가까운 0까지의 최소 거리다.
- 이걸 정석적으로 풀면 "모든 0을 시작점으로 한 BFS"를 사용한다.
- 각 1마다 BFS를 돌리는 구조는 중복 탐색이 너무 많아서 비효율적이다.
- BFS는 시작점에서 가까운 거리부터 퍼지기 때문에 최단거리를 계산하기 좋다.

## 1. 문제의 본질
문제는 각 칸이 다음 값을 가진다.

- `0`: 시작점
- `1`: 거리 계산 대상

우리가 원하는 것은:

```text
각 1칸이 가장 가까운 0까지 얼마나 떨어져 있는가?
```

즉, 한 `1`에서 0까지 찾는 문제가 아니라,
0에서 1로 퍼지며 최소 거리를 계산하는 문제로 바꿀 수 있다.

## 2. 왜 0에서 시작하는가
정답은 결국 "0까지의 거리"다.

그래서 다음과 같이 생각하면 편하다.

- 시작점 = 모든 0
- 거리 = 한 칸 이동할 때마다 +1
- 각 1칸은 BFS를 통해 가장 빠르게 도달한 거리값을 받는다.

즉,

```text
1에서 0까지 찾는 문제
=
0에서 1로 퍼지는 최단거리 문제
```

이 둘은 같은 의미다.

## 3. 왜 +1인지
BFS에서 한 번 이동할 때마다 거리는 1씩 증가한다.

예를 들어:

```text
0 -> 1칸 이동 -> 거리 1
0 -> 2칸 이동 -> 거리 2
```

그래서 인접한 칸으로 이동할 때는 항상 다음처럼 계산한다.

```java
dist[nr][nc] = dist[r][c] + 1;
```

이것은,
"현재 칸까지의 거리 + 한 칸 이동"이라는 뜻이다.

## 4. 왜 더 짧은 경로만 갱신하는가
같은 칸에 도달하는 경로는 여러 개가 있을 수 있다.

예를 들어:

```text
0 1 0
1 1 1
```

`(1,1)`은 여러 경로로 도달할 수 있다.

- 경로 A: 거리 2
- 경로 B: 거리 3

이 중 더 짧은 경로만 남겨야 한다.

그래서 조건은 다음과 같다.

```java
if (dist[nr][nc] > dist[r][c] + 1) {
    dist[nr][nc] = dist[r][c] + 1;
}
```

이 뜻은,

> 현재 경로가 더 짧다면 갱신하고, 더 길면 무시한다.

즉, 각 칸은 최단거리만 남게 된다.

## 5. 왜 1마다 BFS를 돌리면 안 되나
내가 이전에 썼던 방식은 각 `1`마다 BFS를 돌렸다.

```java
for (int row = 0; row < m; row++) {
    for (int col = 0; col < n; col++) {
        if (mat[row][col] == 1) {
            BFS from (row, col);
        }
    }
}
```

이건 각 칸마다 같은 주변을 다시 탐색하게 만든다.

그래서 최악의 경우:

```text
O((m * n)^2)
```

정도의 중복 탐색이 발생한다.

이 문제에서 `m * n <= 10^4` 정도라면,

- 정석은 `O(m * n)`
- 비효율적인 방식은 `O((m * n)^2)`

이 되기 때문에 타임아웃이 날 수 있다.

## 6. 왜 정석은 O(m * n)인가
정석 BFS는 이 구조다.

- 모든 `0`을 시작점으로 queue에 넣음
- 한 번의 BFS로 전체 격자를 탐색
- 각 칸이 최단거리를 계산함

이 경우 각 칸은 보통 한 번씩만 처리된다.

그래서 전체 시간복잡도는 대략:

```text
O(m * n)
```

이 된다.

## 7. 시간복잡도 감각
코딩테스트에서 보통 이런 감각으로 봐야 한다.

- O(1), O(log n), O(n), O(n log n): 보통 안전
- O(n^2): n이 10^3 ~ 10^4 수준이면 가능할 수도 있음
- O((n^2)) 같은 중첩 탐색: 위험

이 문제에서는:

- `m * n`이 10^4 수준
- O(m * n) = 안전
- O((m * n)^2) = 위험

그래서 정석 BFS가 맞다.

## 8. 정석 코드
```java
class Solution {
    public int[][] updateMatrix(int[][] mat) {
        int m = mat.length;
        int n = mat[0].length;
        int[][] dist = new int[m][n];
        Queue<int[]> q = new ArrayDeque<>();
        int[][] dirs = {{-1,0},{1,0},{0,-1},{0,1}};

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (mat[i][j] == 0) {
                    q.offer(new int[]{i, j});
                    dist[i][j] = 0;
                } else {
                    dist[i][j] = Integer.MAX_VALUE;
                }
            }
        }

        while (!q.isEmpty()) {
            int[] cur = q.poll();
            int r = cur[0];
            int c = cur[1];

            for (int[] dir : dirs) {
                int nr = r + dir[0];
                int nc = c + dir[1];

                if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
                if (mat[nr][nc] == 1 && dist[nr][nc] > dist[r][c] + 1) {
                    dist[nr][nc] = dist[r][c] + 1;
                    q.offer(new int[]{nr, nc});
                }
            }
        }

        return dist;
    }
}
```

## 9. 정리
핵심은 다음 한 문장이다.

> 각 1마다 BFS를 돌리는 건 중복 탐색이 너무 많고,
> 0을 시작점으로 한 BFS를 돌리면 한 번에 최단거리를 계산할 수 있다.

이게 바로 이 문제의 핵심 아이디어다.
