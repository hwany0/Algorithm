# 2026-10-30 Populating Next Right Pointers in Each Node

## 오늘의 핵심
오늘은 Populating Next Right Pointers in Each Node 문제를 풀었다.

이 문제는 같은 레벨의 노드들을 연결해서, 각 노드의 `next` 포인터를 다음 오른쪽 노드로 연결하는 문제다.

예를 들어 아래 트리에서:

```text
        1
      /  \
     2    3
    / \  / \
   4  5  6  7
```

결과는 다음처럼 각 레벨의 노드들이 연결되어야 한다.

```text
1 -> null
2 -> 3 -> null
4 -> 5 -> 6 -> 7 -> null
```

핵심은 "같은 레벨의 노드들만 연결"하는 것이다.

## 1. 문제 이해
각 노드의 `next`는 같은 레벨에서 바로 오른쪽에 있는 노드를 가리켜야 한다.

즉,

- `2.next`는 `3`
- `4.next`는 `5`
- `5.next`는 `6`
- `6.next`는 `7`

이 조건을 만족해야 한다.

이 문제에서 중요한 점은, 자식 노드들만 연결하는 것이 아니라
"현재 레벨에서 이미 큐에 들어가 있는 노드들을 순서대로 연결해주는 것"이다.

## 2. 내가 생각한 방식
내가 고민했던 포인트는 다음이었다.

- 현재 노드의 `next`를 어디에 연결할지
- 현재 레벨에서 마지막 노드까지 왔을 때는 `next`를 `null`로 두어야 하는지
- 각 레벨 안에서 `q.peek()`을 이용해서 다음 노드를 찾을 수 있는지

결국 나는 큐를 이용해서 같은 레벨의 노드들을 순서대로 처리하고,
현재 노드가 마지막이 아니면 `q.peek()`를 통해 다음 노드를 연결했다.

## 3. 구현 코드
```java
class Solution {
    public Node connect(Node root) {
        return bfs(root);
    }

    public Node bfs(Node root) {
        if (root == null) return null;

        Queue<Node> q = new ArrayDeque<>();
        q.offer(root);

        while (!q.isEmpty()) {
            int size = q.size();

            for (int i = 0; i < size; ++i) {
                Node n = q.poll();

                if (size - i > 1) {
                    n.next = q.peek();
                }

                if (n.left != null) q.offer(n.left);
                if (n.right != null) q.offer(n.right);
            }
        }

        return root;
    }
}
```

## 4. 핵심 아이디어
### 1) Queue로 같은 레벨을 처리한다
```java
int size = q.size();
for (int i = 0; i < size; ++i) {
    Node n = q.poll();
```

이 부분은 현재 레벨의 노드 수만큼만 처리한다는 의미다.

### 2) 다음 노드를 `q.peek()`으로 확인한다
```java
if (size - i > 1) {
    n.next = q.peek();
}
```

현재 노드가 마지막 노드가 아니라면,
큐의 맨 앞에 있는 다음 노드가 바로 같은 레벨의 다음 노드다.

그래서 현재 노드의 `next`를 그 노드로 연결한다.

### 3) 마지막 노드는 `null`
마지막 노드라면 다음 노드가 없으므로 `next`는 자동으로 `null` 상태가 된다.

## 5. 왜 `peek()`이 가능한가
`Queue`에서 `poll()`은 맨 앞의 원소를 꺼내고,
`peek()`은 꺼내지 않고 현재 맨 앞 원소를 확인만 한다.

즉,

- 현재 노드를 꺼내고
- 아직 남아 있는 큐의 맨 앞 원소가 다음 노드다

그래서 현재 노드의 `next`를 `q.peek()`로 연결하는 것이 가능하다.

## 6. 이 방식의 장점
이 방식은 같은 레벨의 다음 노드가 큐에 남아 있는 구조를 이용해서,
직접 연결을 단순하게 처리할 수 있다.

즉,

- 현재 레벨의 노드를 순서대로 꺼내며 처리한다.
- 다음 노드가 큐에 있다면 그걸 `next`로 연결한다.
- 마지막 노드면 `null` 그대로 둔다.

이 로직은 문제를 매우 간단하게 해결한다.

## 7. 시간 복잡도
- 각 노드는 큐에 한 번 들어가고, 한 번 나간다.
- 전체 노드 수가 `n`개라면

결과적으로:

- 시간 복잡도: `O(n)`
- 공간 복잡도: `O(w)`
  - `w`는 가장 넓은 레벨의 노드 수

## 8. 같은 레벨 연결의 핵심 포인트
트리 문제에서 레벨 연결 문제는 보통 아래 패턴을 기억하면 좋다.

- 같은 레벨의 노드들을 큐로 처리한다.
- 현재 레벨에서 다음 노드가 있으면 `next`를 연결한다.
- 마지막 노드면 `next = null`로 마무리한다.

이 패턴은 주로 BFS 기반으로 자주 나온다.

## 9. 오늘의 결론
오늘 풀었던 문제는 단순히 자식을 연결하는 문제가 아니라,

"같은 깊이의 노드들을 서로 연결해주는 문제"였다.

내가 고민했던 핵심은 다음이었다.

- 현재 노드의 오른쪽 형제 노드를 어떻게 찾는가
- 그 찾는 기준은 현재 레벨의 큐에서의 위치다
- 마지막 노드가 아니면 `q.peek()`로 다음 노드를 확인한다

이 아이디어를 통해 문제를 해결할 수 있었다.

이 문제는 BFS와 연결 구조를 함께 이해하는 데 매우 좋은 연습이었다.
