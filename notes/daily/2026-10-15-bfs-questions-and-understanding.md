# 2026-10-15 BFS 핵심 정리

## 오늘의 핵심 결론
BFS는 "시작점에서 가까운 정점부터 넓게 퍼지는 탐색"이다.

- 자료구조: 큐(Queue)
- 목적: 최단 거리, 최소 이동 횟수, 연결 여부 확인
- 특징: 가까운 노드부터 처리하기 때문에 거리 문제에 강함

## BFS의 기본 동작
1. 시작점을 큐에 넣는다.
2. 큐에서 노드를 꺼낸다.
3. 인접 노드를 확인한다.
4. 아직 방문하지 않은 노드라면 방문 처리 후 큐에 넣는다.
5. 큐가 비워질 때까지 반복한다.

핵심은 "먼저 들어간 것부터 처리한다"는 점이다.
이 방식 때문에 시작점에서 가까운 노드부터 확장된다.

## 왜 BFS가 최단거리 문제에 강한가
BFS는 시작점에서 거리 0, 1, 2, ... 순서로 확장한다.
그래서 먼저 발견한 노드가 보통 가장 짧은 경로로 도달한 노드다.

예를 들어 그래프가 다음과 같다면:

```text
0 -- 1 -- 3
 \  |
  \ 2 -- 4
```

- 0에서 1, 2는 거리 1
- 0에서 3, 4는 거리 2

BFS는 거리가 1인 노드들을 먼저 처리하고, 그다음 거리 2인 노드들을 처리한다.
그래서 최소 이동 횟수 문제에서 매우 유리하다.

## 그래프 예시와 배열 예시의 차이
### 1) 직접 그래프가 주어지는 경우
```text
0: [1, 2]
1: [0, 3]
2: [0, 4]
3: [1]
4: [2]
```

- 정점: 0, 1, 2, 3, 4
- 간선: 각 정점에 연결된 정점들
- BFS는 이 정점들을 큐로 순회한다.

### 2) 배열 또는 미로가 주어지는 경우
```text
[1, 1, 1]
[0, 0, 1]
[1, 1, 1]
```

이건 직접 그래프가 아니라 좌표 배열이다.
그래서 문제를 그래프로 바꾸어야 한다.

- 각 칸 = 정점
- 상하좌우 이동 = 간선
- 1인 칸은 통로, 0인 칸은 벽

중요한 점:
- 인접한 칸이라고 해서 모두 간선이 되는 것은 아니다.
- 실제로는 "인접 + 통로여야 함"이 조건이다.

예를 들어 (0,0)에서 (1,0)은 0이므로 벽이고, (0,1)은 1이므로 통로다.
그래서 실제로는 (0,0)과 (0,1)만 연결된다고 생각하면 된다.

## 배열 문제를 그래프로 바꾸는 방식
코딩테스트에서 자주 보는 문제는 그래프 형태로 직접 주어지지 않는다.
보통은 이런 형태다:

- 미로
- 지도/격자
- 좌표 이동
- 네트워크 연결
- 상태 전이

이럴 때는 다음처럼 생각하면 된다.

- 무엇이 정점인가?
- 어떤 조건에서 이동 가능한가?
- 어떤 상태를 방문했는가?

이렇게 정의하면 그래프처럼 문제를 바꿀 수 있다.

## Java BFS 기본 패턴
```java
import java.util.*;

public class BFSExample {
    public static void bfs(int start, Map<Integer, List<Integer>> graph) {
        Queue<Integer> queue = new ArrayDeque<>();
        Set<Integer> visited = new HashSet<>();
        Map<Integer, Integer> distance = new HashMap<>();

        queue.offer(start);
        visited.add(start);
        distance.put(start, 0);

        while (!queue.isEmpty()) {
            int current = queue.poll();

            for (int next : graph.getOrDefault(current, Collections.emptyList())) {
                if (!visited.contains(next)) {
                    visited.add(next);
                    distance.put(next, distance.get(current) + 1);
                    queue.offer(next);
                }
            }
        }
    }
}
```

이 코드는 다음을 뜻한다.

- queue: 다음에 방문할 노드를 저장
- visited: 중복 방문 방지
- distance: 시작점에서 각 노드까지의 거리

## 핵심 정리
- BFS는 "가까운 것부터 넓게 퍼지는 탐색"이다.
- 큐를 사용한다.
- 방문 여부를 꼭 체크한다.
- 최단 거리 문제에서 강하다.
- 배열/미로 문제는 좌표를 정점으로 보고 이동 가능 조건을 간선으로 생각하면 된다.

## 오늘의 정리
핵심은 문제를 그래프로 바꿔서 바라보는 것이다.

그래프 문제든 배열 문제든,
BFS는 결국 "시작점에서 점점 확장하며 방문하는 방식"으로 동작한다.

그래서 "최소 이동", "최단거리", "가장 가까운 경로" 같은 표현이 나오면 BFS를 먼저 떠올리면 된다.
