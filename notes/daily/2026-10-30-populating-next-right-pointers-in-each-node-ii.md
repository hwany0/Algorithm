# 2026-10-30 Populating Next Right Pointers in Each Node II

## 오늘의 핵심
오늘은 Populating Next Right Pointers in Each Node II 문제를 풀었다.

이 문제는 같은 레벨의 노드들을 연결하는 문제인데,
앞의 116번과 비슷하지만 차이점이 있다.

- 116번은 완전 이진 트리였다.
- 117번은 완전 이진 트리가 아니라, 각 노드의 자식이 비어 있을 수 있다.

그래서 단순히 `node.left`와 `node.right`만 보는 방식으로는 부족하고,
"현재 레벨에서 다음 노드를 어떻게 찾는지"를 더 신경 써야 한다.

## 1. 문제 이해
각 노드는 같은 레벨의 다음 노드를 `next`로 연결해야 한다.

예를 들어 아래 트리가 있다면:

```text
        1
      /  \
     2    3
    / \     \
   4   5     7
```

결과는:

```text
1 -> null
2 -> 3 -> null
4 -> 5 -> 7 -> null
```

핵심은 자식이 없는 노드도 있다는 점이다.

그래서 같은 레벨의 다음 노드를 연결할 때,
"큐에 남아 있는 다음 노드"를 기준으로 연결하는 방식이 필요하다.

## 2. 내가 생각한 방향
이 문제는 116번과 비슷하게 BFS로 풀었다.

내가 중요하게 생각한 포인트는 다음이었다.

- 현재 레벨의 노드들만 처리한다.
- 각 노드를 꺼내면서 다음 노드가 있는지 확인한다.
- 마지막 노드면 `next = null`로 둔다.
- 자식이 있는 노드는 다음 레벨로 큐에 넣는다.

이번 문제에서는 왼쪽/오른쪽 자식이 모두 있을 수도 있고,
한쪽만 있을 수도 있다.

그래서 `n.left`/`n.right`를 직접 묶는 것이 아니라,
현재 레벨의 큐 순서를 활용해서 다음 노드를 찾는 방식이 더 확실하다.

## 3. BFS 구현
```java
class Solution {
    public Node connect(Node root) {
        if (root == null) return null;

        Queue<Node> q = new ArrayDeque<>();
        q.offer(root);

        while (!q.isEmpty()) {
            int size = q.size();

            for (int i = 0; i < size; i++) {
                Node node = q.poll();

                if (i < size - 1) {
                    node.next = q.peek();
                }

                if (node.left != null) q.offer(node.left);
                if (node.right != null) q.offer(node.right);
            }
        }

        return root;
    }
}
```

## 4. 핵심 포인트
### 1) 현재 레벨만 처리한다
```java
int size = q.size();
for (int i = 0; i < size; i++) {
```

이 부분으로 같은 레벨만 처리한다는 사실을 보장한다.

### 2) 다음 노드는 `q.peek()`로 확인한다
```java
if (i < size - 1) {
    node.next = q.peek();
}
```

현재 노드를 꺼낸 이후, 큐의 맨 앞에 있는 노드는 바로 같은 레벨의 다음 노드다.

그래서 `next`를 연결할 수 있다.

### 3) 마지막 노드는 `null`
마지막 노드라면 다음 노드가 없으므로 그대로 `null`이다.

이것이 자연스럽게 문제 조건을 만족한다.

## 5. 왜 116번과 다른가
116번은 완전 이진 트리라서,
각 노드의 왼쪽 자식과 오른쪽 자식이 항상 존재한다면 더 간단한 방식으로 연결할 수 있다.

하지만 117번은 어떤 노드는 자식이 없을 수도 있다.

그래서 "현재 노드의 left/right를 직접 연결"하는 방식이 아니라,
"큐에서 순서대로 다음 노드를 찾는 방식"이 더 안전하다.

즉,

- 116번: 구조가 더 정형화되어 있음
- 117번: 빈 자식이 있을 수 있어서, 동일 레벨의 다음 큐 원소를 기준으로 연결해야 함

## 6. 시간 복잡도
모든 노드를 한 번씩 큐에 넣고 뺀다.

- 시간 복잡도: `O(n)`
- 공간 복잡도: `O(w)`
  - `w`는 가장 넓은 레벨의 노드 수

## 7. 오늘의 결론
117번도 결국 같은 패턴이다.

- BFS로 같은 레벨 처리
- 같은 레벨의 다음 노드를 `q.peek()`로 연결
- 마지막 노드는 `next = null`

이 방식은 구조가 불완전한 트리에서도 잘 먹힌다.

116번과 117번은 비슷하지만,
117번은 자식이 비어 있는 경우까지 고려해야 해서
"큐의 순서를 기반으로 연결"하는 사고가 더 중요하다.

이 문제를 통해 같은 레벨 연결 문제에서는
"다음 노드가 현재 큐에서 어디에 있는지"를 보는 감각을 익혔다.
