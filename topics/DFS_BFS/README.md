# DFS / BFS

## DFS
깊이 우선 탐색. 경로를 따라가며 방문하고, 조건에 따라 재귀 또는 스택을 사용한다.

## BFS
너비 우선 탐색. 큐를 사용하며 최단 경로 문제에 자주 사용된다.

## 차이점
- DFS: 경로 탐색, 백트래킹, 연결 요소 탐색
- BFS: 최단 거리, 레벨 탐색, 그래프 너비 기반 탐색

## 핵심 체크 포인트
- 방문 여부를 관리한다.
- 재귀 깊이 제한을 고려한다.
- 그래프가 연결 리스트인지, 인접 행렬인지 확인한다.
- 큐 / 스택 처리 순서를 명확히 이해한다.

## 대표 문제
- Number of Islands
- Flood Fill
- Binary Tree Level Order Traversal
- Shortest Path in Graph
