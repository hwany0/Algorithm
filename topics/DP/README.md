# DP (Dynamic Programming)

## 정의
동적 계획법은 큰 문제를 작은 하위 문제로 나누어, 이전 결과를 재사용해 최적해를 계산하는 방식입니다.

## 핵심 아이디어
- 중복된 부분 문제를 재사용한다.
- 상태를 정의한다.
- 점화식을 세운다.
- 메모이제이션 또는 Bottom-up 방식으로 해결한다.

## 대표 문제
- Climbing Stairs
- Knapsack
- Longest Increasing Subsequence
- Coin Change

## 주의할 점
- 상태 정의를 명확히 해야 한다.
- 점화식이 잘못되면 전체 풀이가 틀린다.
- 메모리 사용량과 시간 복잡도를 함께 고려해야 한다.

## 연습 포인트

- 점화식을 설명할 수 있게 쓰기
- 1D / 2D DP의 차이 이해하기
